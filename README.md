Este repositorio contiene el código fuente de mi página web personal, diseñada para exponer mi perfil profesional, proyectos técnicos y formas de contacto. 

Dado que mi enfoque profesional es la arquitectura, optimización y lógica de servidor (Backend), la capa de presentación (Frontend) de este portafolio fue desarrollada como un complemento funcional. Me apoyé en herramientas modernas e inteligencia artificial para agilizar el diseño de la interfaz, permitiéndome mantener mi esfuerzo y atención en la construcción de sistemas robustos en el lado del servidor.
